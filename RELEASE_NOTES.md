# ELECTRO 4.4.0 — workbench feature update

Version code 28. Existing application ID and signing identity are retained.

- Compact primary header and search; all Tools category controls are visible.
- Unit converter has adjacent unit controls, live results, a calculation explanation, Reset, saved conversions and expandable assumptions. Temperature conversion remains explicitly absolute.
- Compare up to three bundled database entries side by side, including their source URLs. Missing specifications are labeled rather than invented.
- New offline Binary / Decimal / HEX converter with printable ASCII lookup and bounded input validation.
- Illustrated learning pages, English/Tamil lesson selection, fresh-install white theme and existing-user theme preservation.
- Existing calculator formulas, favourites, saved calculations, pin orientation notes and mandatory major-update behavior are retained.

Photo recognition, a general circuit simulator, expanded verified MCU specifications and additional oscilloscope lessons are not included in this release. Physical-device validation is not claimed.
