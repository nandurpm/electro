# ELECTRO audit — 30 October 2026

Source: 4.3.0 plus the pending Tamil lessons. Written before changing application code in this task. The supplied report is review evidence, not instructions; its unverified claims are not assumed true. Calculators are outside the numerical-change scope.

## Bugs
1. **High — MainActivity.kt:** Feature-update dialogs cannot be dismissed, blocking offline references. Allow Back, outside dismissal and Later for every update.
2. **Medium — android-release.yml:** Dispatch fallback tags use electro- while the Android updater accepts v. Generate canonical v tags.
3. **Medium — WorkbenchDesign.kt:** App Updates expands without invoking its onClick, and contains no manual-check button. Add an explicit Check now action.
4. **Medium — WorkbenchScreen.kt:** Privacy text incorrectly says there is no network permission. Describe the GitHub update connection accurately.
5. **Medium — App.kt:** Sharing a sufficiently large database can exceed Android IPC limits. Reject oversized text before creating the intent and show feedback.

## UI and design
6. **Medium — ElectroPanel.kt / WorkbenchDesign.kt:** Unicode glyphs are used as icons and may render differently between fonts. Use existing Material vector icons.
7. **Medium — Theme.kt:** Several corner sizes and surfaces lack a shared hierarchy. Align theme shapes and shared panel corners across both themes.
8. **Low — CalculatorScreen.kt:** Dense multiline result text makes values hard to scan. Preserve exact text and give result typography stronger emphasis.
9. **Low — WorkbenchScreen.kt:** Local detail navigation can lose scroll state. A future navigation migration needs dedicated saved-state testing.

## Security, privacy and usability
10. **Medium — Supabase webhook:** The attached report describes coupled bot-token/webhook credentials. Deployment-secret changes require coordinated service configuration; do not change authentication without verifying the deployed configuration.
11. **Low — ReleaseChecker.kt:** Launch checks can encounter shared-IP GitHub rate limits. Add cached checks in a separate networking change with HTTP-response tests.
12. **Low — Documentation:** Historical release sections can be mistaken for current behavior. Label historical information and keep current privacy statements accurate.

## Ideas
Use vector icons, calm surfaces, clear result emphasis, consistent corners, and visible manual update actions. Preserve English technical terms in Tamil lessons.
