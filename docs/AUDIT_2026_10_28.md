# Audit follow-up — 28 October 2026

Reviewed against source commit 17f4bbe (3.3.0, code 19). This change is a correctness and build-process batch, not a new signed release. Existing user mode indices and stored preferences are preserved.

## Implemented

- B1/B2: known non-prefixable units render plainly; large numbers avoid scientific notation and monetary cost uses two decimals. Unit metadata is still derived from labels in the legacy calculator UI.
- B3/B4/B5: tolerant upward E-series selection, conventional trailing-R SMD notation, blank list entries ignored and decimal-dot/separator rules stated explicitly. Commas remain list separators for compatibility.
- B6–B9/B11/B12: optional series resistance for reactance, physically valid cable temperatures, tolerant unity power factor, ASCII numeric parsing and locale-independent SMD indices, case-insensitive scientific expressions, explicit unknown-tool errors, corrected battery formula comment.
- S1–S4: gate describes hiding references rather than encryption, component filtering has a model flag, backgrounding locks access (rotation preserves it), stale asynchronous unlocks cannot reopen it, wrapped activity contexts work, errors are announced and IME Done submits.
- D2/D3: input writes debounce for 350 ms and flush at lifecycle stop; calculator results are remembered across unrelated recompositions. Abrupt termination during the debounce can still lose the latest edit.
- D7/D9–D12/D14: safe USB table indexing, explicit loading-error contrast, confirmation before damaged-preference reset, one theme selector, additional converter units, redundant theme writes avoided; both reset paths clear colour-band results.
- A2/A3: heading semantics, decorative search icon removed from announcements, gate error announcements, diagram text respects font scaling.
- St1: comment checks exclude private/internal declarations and test methods; one misleading renderer parameter comment corrected.
- S6/P1/P2/P5: push version comparison uses the event base; same-commit tag dispatch can retry; unnecessary release permission removed; CI builds/tests/lints debug and release; weekly dependency update proposals; current README version and visible-system-bar documentation; generated source listings and verification become build artifacts rather than tracked copies. Contrast baseline remains tracked independently.
