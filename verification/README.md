# Verification artifacts

The previous APK badging and summary files were removed because they described version 2.0.3 (versionCode 12), while the current source is version 2.1.0 (versionCode 13). They must be regenerated by CI from the current build before release.

Run the Android CI workflow, then commit the generated verification artifacts only after confirming that their APK version, hash, tests, and lint results match the source revision.
