# ELECTRO animated Home preview

Actual Android Compose renders from the animated homepage branch based on ELECTRO 4.3.3. The GIF contains 64 real frames over eight seconds. It shows a slowed preview of the actual circuit/multimeter animation, not a mockup. Static images show the dark and light layouts.

Includes a floating multimeter illustration, circuit energy dots, illustrated launcher icons, staggered entrance and press feedback. Artwork motion stops when the app is paused or system animations are disabled. Calculators, saved data, navigation, language preferences and mandatory major updates remain connected to the original app.
