# ELECTRO release downloads

This branch contains the published **3.0.2 release files**, not the Android source tree. It must not be merged into `main`.

- [Open the current Android source on main](https://github.com/nandurpm/electro/tree/main)
- [Open the release download page](https://github.com/nandurpm/electro/releases/tag/electro-3.0.2)
- [Download the signed APK](https://github.com/nandurpm/electro/releases/download/electro-3.0.2/ELECTRO-3.0.2-SIGNED.apk)
- [Download matching 3.0.2 source ZIP](https://github.com/nandurpm/electro/releases/download/electro-3.0.2/ELECTRO-3.0.2-source.zip)

The latest Step 1 UI work is on `main`; the 3.0.2 APK predates that step. GitHub's yellow Compare & pull request banner is a standard recent-push notice, not a build error.

The encrypted signing backup is for the repository owner only. Keep its password and decrypted contents private.
